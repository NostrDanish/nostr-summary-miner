# Security Audit — nostr-summary-miner — 2026-10-20

## Summary
Single-file Python experiment (miner.py, read in full): keyword-classifies events from a hardcoded public nostr-summary feed npub. No secrets, no signing. Findings: 0C / 0H / 1M / 1L.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| M1 | MEDIUM | miner.py `mine()` | `websocket.create_connection(..., sslopt={"cert_reqs": ssl.CERT_NONE})` — TLS verification disabled on the relay connection; MITM can feed forged events into the classifier output. | Remove the sslopt override. |
| L1 | LOW | miner.py | Events are never signature-verified and classified purely on keywords (design-level, fine for an experiment). Hardcoded feed npub is a public key — not a secret. | Optionally verify event sigs; document trust model. |

## Secrets Check
miner.py read in full — contains one hardcoded **public npub** (not a secret) and public relay URLs. Org-wide searches for `nsec1`, `sk-`, `xai-`, `nostr+walletconnect://`, `PRIVATE KEY` — **no secrets found**.
